## 1. 模块职责

**只负责「声音进系统并变成文字」**，不负责语义理解、挂号流程、TTS、嘴型。

对外唯一门面建议命名为 `VoiceInput`：

| 方法 | 含义 |
|---|---|
| `start()` | 开始一轮收音 |
| `stop()` | 正常结束，等待 final |
| `abort()` | 打断，丢弃本轮 |
| `pause()` / `resume()` | 预留（电视切后台等） |

| 事件 | 含义 |
|---|---|
| `ready` | 麦克风与通道就绪 |
| `speech.start` / `speech.end` | VAD 判定人声起止 |
| `level` | 音量，驱动波形 UI |
| `partial` | 中间结果（上屏用） |
| `final` | 最终文本 + 置信度 |
| `error` | 可恢复/不可恢复错误码 |
| `silence` | 静音超时 |

## 2. Demo 三通道（必须可切换）

| 通道 ID | 名称 | 适用 | 说明 |
|---|---|---|---|
| `browser` | 浏览器识别 | 零配置联调 | Web Speech API；Chrome 国内常失败 |
| `cloud` | 云端 ASR | 主推稳定路径 | 录音经服务端代理；OpenAI 兼容或讯飞适配 |
| `mock` | 演示模式 | 无麦/断网 | 预设语句逐字 partial |

切换方式：

- 运行时：设置面板或快捷键（对齐交付包 1/2/3）  
- 配置：`server/config.json` → `asr.provider` / `asr.enabled`  
- 失败降级顺序默认：`browser → cloud → mock`（可由 api-switch 覆盖）

## 3. 数据流（目标规格）

```text
getUserMedia
  → 浏览器 NS/AEC/AGC（能开则开）
  → 重采样到 16kHz 单声道
  → VAD（双阈值 + 预卷）
  → 分帧 / 或整段 MediaRecorder（Demo 云通道可先整段）
  → 传输（HTTPS/localhost 代理）
  → ASR Provider
  → 后处理（热词、置信度）
  → partial / final 事件
```

Demo 优先级：

1. P1：三通道可用 + partial/final 上屏  
2. P2：云通道整段转写（实现快）  
3. P3：流式 WebSocket ASR（降首字延迟）  
4. P4：AudioWorklet + 40ms PCM + 300ms 预卷（对齐交付包目标规格）

## 4. 默认识别参数表（可配置）

以下为 Demo 默认值，写入 `server/config.json` 的 `asr.params` 与前端可读副本（不含密钥）。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `sampleRate` | `16000` | 送 ASR 的采样率 |
| `channels` | `1` | 单声道 |
| `bitDepth` | `16` | PCM 位深（流式时） |
| `frameMs` | `40` | 分帧时长（流式） |
| `vadStartRatio` | `3.0` | 相对底噪，开始说话阈值倍数 |
| `vadStartHoldMs` | `200` | 超过起始阈值需持续毫秒 |
| `vadContinueRatio` | `1.8` | 维持说话阈值倍数 |
| `silenceStopMs` | `1000` | 静音判停 |
| `preRollMs` | `300` | 预卷，防吞老人首字 |
| `minSpeechMs` | `300` | 最短有效语音 |
| `maxSpeechMs` | `20000` | 最长一句话 |
| `lowConfidence` | `0.6` | 低于此值不直接入槽，引导重复 |
| `finalWaitMs` | `2000` | stop 后等待 final 超时 |
| `language` | `zh-CN` | 普通话；预留 `zh-HK` |
| `medicalHotwords` | 数组 | 科室/症状热词表（Demo 内置一小份） |

浏览器通道额外：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `browserSilenceMs` | `1200` | 无新 interim 则结束 |
| `browserLang` | `zh-CN` | SpeechRecognition.lang |

## 5. Provider 接口

```js
/**
 * ASR Provider 统一接口。
 * 不同厂商（OpenAI 兼容、科大讯飞等）都实现同一套方法，方便 api-switch 热切换。
 */
export class AsrProvider {
  /** @returns {Promise<void>} */
  async connect(session) {}

  /** 送入音频块或整段 Blob */
  sendAudio(chunk) {}

  /** 正常结束本轮 */
  finish() {}

  /** 立即取消 */
  abort() {}

  /** 订阅 partial/final/error */
  on(event, handler) {}
}
```

### 5.1 OpenAI 兼容（SenseVoice / 通义兼容网关等）

- Demo 路径：`POST /api/asr`，服务端组 multipart 调 `/audio/transcriptions`  
- 配置：`baseUrl`、`apiKey`、`model`  
- 优点：换厂商常只需改 URL + model  

### 5.2 科大讯飞（适配器位）

- 单独实现 `XfyunAsrProvider`，不强迫塞进 OpenAI 形状  
- 配置项建议：`appId`、`apiKey`、`apiSecret`、`accent`、`vad_eos`  
- 鉴权与 WebSocket 只放在 **server 适配层**，前端仍只打自家 `/api/asr/*`  
- Demo 可先做「录音文件一句话转写」；流式听写作为增强  

### 5.3 MockProvider

- 内置 8–12 句挂号相关话术（如「我最近总是头晕」「挂明天上午」）  
- 定时吐 partial，最后 final，置信度固定 `0.99`

## 6. 安全与隐私（语音侧）

| 要求 | Demo 做法 |
|---|---|
| 麦克风权限 | 仅 localhost / HTTPS；失败给大字指引 |
| 音频不落前端可下载目录 | 默认不落盘；调试开关才保存 |
| Key | 仅服务端 |
| 日志 | 只记文本与时长，不默认存原始音频 |
| 用户知情 | 设置页说明「正在使用麦克风做挂号演示」 |

## 7. 与编排层的衔接

```text
VoiceInput.final
  → core.safetyGuard（危急词）
  → 若在挂号槽位中：registration 填槽
  → 否则：intentRouter → ai 或技能
```

低置信度（`< lowConfidence`）：

- 不写入关键槽位（就诊人、确认「对」）  
- 数字人提示「我没听清，请再说一次」或弹出大按钮  

打断时语音侧必须：

1. `abort()` 当前 ASR  
2. 清空发送队列  
3. 重置 VAD 状态  
4. 保留 pre-roll 缓冲（若已实现）

## 8. 验收用例（语音模块）

| 编号 | 场景 | 期望 |
|---|---|---|
| V1 | localhost 授权麦克风 | `ready` 成功 |
| V2 | browser 通道说话 | 有 partial 与 final |
| V3 | browser 报 network | 自动降级 cloud 或 mock |
| V4 | cloud 配置正确 | `/api/asr` 返回文本 |
| V5 | mock 无麦 | 完整一轮对话可走通 |
| V6 | 空格打断 | 立即停录，无幽灵 final 入槽 |
| V7 | 静音超时 | `silence` + 友好提示 |
| V8 | 切换 provider | 下一轮即用新通道，无需改业务代码 |
