## 1. 约定

| 项 | 约定 |
|---|---|
| Base URL | 开发：`http://127.0.0.1:5173`（或 Vite 代理到 Node） |
| 数据格式 | JSON；ASR 上传可用 multipart |
| 鉴权 | Demo：`Authorization: Bearer <deviceSessionToken>`（除公开配置、同意、创建绑定、手机确认、埋点） |
| 错误体 | `{ "code": "STRING", "message": "对人友好的中文", "detail": {} }` |
| 幂等 | 写接口支持头 `Idempotency-Key` 或 body 字段 |
| Provider | 标注「可切换」的接口由 api-switch / config 决定上游 |

通用错误码：

| code | 含义 |
|---|---|
| `UNAUTHORIZED` | 会话无效 |
| `FORBIDDEN` | 跨家庭等 |
| `VALIDATION` | 参数错误 |
| `RATE_LIMIT` | 限流 |
| `UPSTREAM` | 云厂商失败（可降级） |
| `HOLD_EXPIRED` | 预占过期 |
| `BIND_EXPIRED` | 绑定码过期 |
| `BIND_CODE_INVALID` | 6 位码错误 |
| `CONSENT_REQUIRED` | 未同意就请求出码 |
| `CONFLICT` | 号源冲突 |
| `NOT_FOUND` | 资源不存在 |

## 2. 系统与 Provider 接口

### 2.1 GET `/api/config`

| 项 | 内容 |
|---|---|
| 用途 | 前端拉取通道可用性与调控展示值 |
| 可切换 | 否（元数据） |
| 鉴权 | 否 |

响应（示意，无 Key）：

```json
{
  "asr": { "activeId": "asr.mock", "providers": [{ "id": "asr.mock", "enabled": true, "label": "演示" }] },
  "llm": { "activeId": "llm.script", "providers": [] },
  "tts": { "activeId": "tts.browser", "rate": 0.88 },
  "bind": { "activeVariant": "A", "variants": ["A", "B", "C"] },
  "params": { "asr": { "language": "zh-CN", "lowConfidence": 0.6 } }
}
```

### 2.2 POST `/api/providers/activate`

| 项 | 内容 |
|---|---|
| 用途 | 测试时切换当前 Provider |
| body | `{ "type": "asr"|"llm"|"tts", "id": "asr.cloud" }` |
| 可切换 | 本接口即切换入口 |

### 2.3 POST `/api/bind/variant`

| 项 | 内容 |
|---|---|
| 用途 | 演示时切换绑定人机实验流 |
| body | `{ "variant": "A"|"B"|"C" }` |
| 说明 | 影响下一轮 `createBindSession` 默认 variant；见 08 |

### 2.4 POST `/api/chat`

| 项 | 内容 |
|---|---|
| 用途 | 代理 LLM 流式对话 |
| 可切换 | **是**（llm.activeId） |
| body | `{ "messages": [], "temperature?: number", "maxTokens?: number" }` |
| 响应 | `text/event-stream` SSE |

### 2.5 POST `/api/asr`

| 项 | 内容 |
|---|---|
| 用途 | 上传音频转写 |
| 可切换 | **是**（asr.activeId） |
| body | multipart: `file`；或 JSON Base64（二选一，实现时定一种） |
| 响应 | `{ "text": "...", "confidence": 0.92, "providerId": "asr.cloud" }` |

### 2.6 POST `/api/tts`（预留）

| 项 | 内容 |
|---|---|
| 用途 | 云端 TTS；可返回 viseme 时间戳 |
| 可切换 | **是** |
| Demo | 可先 501，前端走 browser TTS |

## 3. 身份与同意

### 3.1 POST `/api/consent/accept`

**必须在创建绑定会话之前调用。**

```json
{
  "version": "consent-2026-11-08",
  "accepted": true,
  "allowFamilyAssist": true
}
```

未同意时，`POST /api/bind/sessions` 返回 `CONSENT_REQUIRED`。

### 3.2 POST `/api/bind/sessions`

创建绑定会话。

请求：

```json
{
  "variant": "A",
  "deviceLabel": "客厅电视"
}
```

响应：

```json
{
  "bindId": "b_xxx",
  "code6": "482917",
  "code6Display": "482 917",
  "qrPayload": "https://hosp.example/b/7K2M9X",
  "variant": "A",
  "expiresAt": "2026-11-08T12:00:00+08:00",
  "status": "PENDING"
}
```

说明：`code6` 与二维码短链同源；`code6Display` 供 UI 3+3 展示。

### 3.3 GET `/api/bind/sessions/:bindId`

轮询状态：`PENDING|SCANNED|CONFIRMED|BOUND|EXPIRED`。

### 3.4 POST `/api/bind/confirm`（手机端）

家人或本人在 H5 确认绑定。

```json
{
  "code": "482917",
  "patientId": "p1",
  "operatorType": "family",
  "assistantAffirmed": true
}
```

| 规则 | 说明 |
|---|---|
| `operatorType=family` | `assistantAffirmed` 必须为 true，否则 `VALIDATION` |
| 码错误 | `BIND_CODE_INVALID` |
| 码过期 | `BIND_EXPIRED` |
| 成功 | 会话进入 `BOUND`；电视轮询拿到 token |

响应：

```json
{
  "status": "BOUND",
  "patientMaskedName": "张*兰",
  "message": "请看电视，绑定已完成"
}
```

### 3.5 POST `/api/bind/sessions/:bindId/mock-confirm`

仅 Demo / 开发者面板：一键模拟手机确认成功，返回 `deviceSessionToken` 与默认家庭/就诊人。

### 3.6 POST `/api/agent/bind`（客服 Mock）

```json
{
  "bindId": "b_xxx",
  "patientId": "p1",
  "operatorId": "agent_demo_01"
}
```

审计：`operatorType=agent`。

### 3.7 POST `/api/device/session/refresh`

刷新 Token（Demo 可简化）。

### 3.8 POST `/api/telemetry/bind`

绑定实验埋点（可批量）。

```json
{
  "bindId": "b_xxx",
  "variant": "B",
  "events": [
    {
      "name": "bind_path_select",
      "ts": "2026-11-08T11:00:00+08:00",
      "props": { "path": "family", "sceneRole": "family_onsite" }
    }
  ]
}
```

约束：禁止写入身份证号、手机号全文、原始音频；只允许枚举与耗时类字段。事件名见 [08 §11](./08-首次绑定人机与实验方案-v1.1.md)。

### 3.9 GET `/api/telemetry/bind/export`

开发者模式导出当前/指定会话 JSONL，用于现场对比 A/B/C。

## 5. 导诊与号源

### 5.1 POST `/api/triage/match`

| body | `{ "slots": { "symptom": "头晕", "bodyPart": "头", "duration": "三天" }, "utterance": "..." }` |
| 响应 | `{ "departmentId": "cardiology", "departmentName": "心血管内科", "confidence": 0.81, "needMore": false, "nextQuestion": null }` |

说明：可在服务端跑规则库；若辅助 LLM，仍须白名单校验科室。

### 5.2 GET `/api/schedule/slots`

Query：`departmentId`、`patientId`（用于资格校验）、`limit=3`。

响应：

```json
{
  "candidates": [
    { "slotId": "s1", "departmentName": "心血管内科", "doctorName": "李医生", "timeText": "明天 上午 9:00", "remain": 5 }
  ]
}
```

## 8. 前端事件契约（非 HTTP）

会话层与模块间建议统一事件名：

| 事件 | 载荷 |
|---|---|
| `asr.partial` | `{ text }` |
| `asr.final` | `{ text, confidence, providerId }` |
| `session.state` | `{ from, to }` |
| `avatar.action` | `{ action }` |
| `registration.step` | `{ step, data }` |
| `bind.variant` | `{ variant }` |
| `bind.code_reread` | `{ bindId }` |
| `safety.emergency` | `{ matched }` |
| `tts.sentence` | `{ text, index }` |

## 9. 可切换性一览

| 接口 | 上游可切换 |
|---|---|
| `/api/asr` | 是 |
| `/api/chat` | 是 |
| `/api/tts` | 是（预留） |
| `/api/triage/match` | 规则固定；可选 LLM 辅助开关 |
| 挂号 hold/confirm | Demo Mock；终态换 Adapter 不改路径 |
| `/api/config`、activate | 切换控制面 |
| `/api/bind/variant` | 人机实验流切换（非云厂商） |
