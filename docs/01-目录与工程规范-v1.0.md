## 1. 技术约定

| 约定 | 说明 |
|---|---|
| 框架 | **仅 Vue 3**（Composition API），不混用 Vue 2 / Options 混搭为默认风格 |
| 构建 | Vite |
| 包管理 | npm（若改用 pnpm/yarn 须在 README 注明） |
| 路由 | 大屏 Demo 可用单页状态机；若页面增多再引入 `vue-router`（引入前说明原因） |
| 全局状态 | 优先模块内 `ref`/`reactive`；跨页共享多了再引入 **Pinia**（引入须更新本规范） |
| UI 库 | Demo 默认不引入 Element Plus / Vant，大屏与遥控器焦点自研 |
| 注释 | 业务与关键逻辑必须有**中文注释**，方便初学者阅读 |
| 交付包 Demo | 位于 `医鸿IPTV数字人-交付包/03-语音对话Demo`，只作参考，不作为最终源码树 |

## 3. 模块边界（硬规则）

| 模块路径 | 负责 | 禁止依赖 |
|---|---|---|
| `modules/voice` | 采集、VAD、ASR Provider 调用、partial/final 事件 | 不知挂号业务、不调 LLM |
| `modules/ai` | 对话生成、剧本、流式解析 | 不直接碰麦克风、不写号源锁 |
| `modules/api-switch` | Provider 注册、激活、降级顺序、调控参数 | 不含 UI 文案业务 |
| `modules/avatar` | 动作状态、精灵帧、嘴型 | 不解析 ASR；只消费「说话中/空闲」信号 |
| `modules/registration` | 挂号全流程子模块 | 不直接 new WebSocket ASR；经 core / voice 事件进入 |
| `core` | 状态机、安全、意图 | 不写死某一家云厂商 SDK |

**挂号模块对外只暴露门面**，例如：

```js
// 示意：registration/index.js
// 其它模块只通过这些方法用挂号能力，方便以后整包替换优化
export function startRegistrationFlow(ctx) {}
export function selectPatient(patientId) {}
export function holdSlot(slotId, idempotencyKey) {}
export function confirmOrder(holdId, idempotencyKey) {}
export function cancelOrder(orderId) {}
```

## 4. 挂号子目录职责

| 子目录 | 职责 | 后续可独立优化点 |
|---|---|---|
| `identity` | 设备会话、绑定码、绑定状态机 | 换真实公众号 / 运营商账号 |
| `family` | 就诊人列表、默认人、L0/L1/L2 切换 | 家庭账户服务 |
| `triage` | 症状槽位、科室匹配知识库 | 医务科审核后的规则引擎 |
| `schedule` | 医生/日期/时段查询与三候选压缩 | 接预约中台缓存 |
| `hold-order` | 预占、确认、取消、幂等 | 真号源锁与订单 |
| `consent` | 明示同意、脱敏策略、审计事件 | 合规与留存策略 |

详细流程见 [04-挂号预约核心模块方案-v1.0.md](./04-挂号预约核心模块方案-v1.0.md)。

## 6. 注释规范（初学者友好）

1. 每个模块入口文件顶部用 3–6 行说明「这个文件夹干什么」  
2. 导出的函数写清：入参、返回、何时调用  
3. 状态机转移、安全拦截、幂等键等关键逻辑必须注释「为什么」  
4. 不写无意义注释（如 `// 赋值`）  
5. 示例：

```js
/**
 * 开始一轮收音。
 * 调用时机：用户按下空格或遥控器确认键，且当前为 IDLE / SPEAKING(打断后)。
 * @param {object} options 可选：通道覆盖、最长秒数
 */
export function startListening(options = {}) {}
```

## 7. 配置与密钥

| 文件 | 谁读 | 是否进 Git |
|---|---|---|
| `server/config.json` | 仅 Node 代理 | 建议忽略真实 Key；提交 `config.example.json` |
| 前端 env | 仅公共项（如 `VITE_API_BASE`） | 可提交无密钥示例 |
| 前端运行时 | `GET /api/config` 只返回 `enabled` 布尔与模型名展示用字段 | Key 永不出网到浏览器 |

## 8. 大屏与输入约定

| 项 | Demo 约定 |
|---|---|
| 设计分辨率 | 1920×1080，整体等比缩放 |
| 主输入 | 键盘空格模拟遥控器「确认/打断」 |
| 通道切换 | 数字键或设置面板切换 ASR/LLM |
| 文字兜底 | 底部输入框，链路与语音 final 相同 |

跨端键值映射放在 `composables/useRemoteKeys.js`，避免写死在页面里。

## 9. 与交付包文件的对应关系

| 交付包文件 | Vue3 落点 |
|---|---|

## 10. 质量门槛（实现阶段）

- 模块间不出现循环依赖  
- 切换 ASR/LLM Provider 不改 `registration` 代码  
- 新增挂号子能力只落在 `registration/*`  
- 关键路径有中文注释  
- 本地 `npm run dev` 可同时起前端与代理（脚本在实现时编写；命令由你本地执行）
