# 安安 v3 · 待机 / 说话动作包

## 怎么最快看效果

解压后双击 `preview-v3.html`（Chrome / Edge 打开即可，不用起本地服务）。
三张卡片：**待机**（眨眼 + 抖耳 + 摆尾）、**说话**（下颌开合）、**状态切换**。
点「开始说话」可以听节奏——注意它不是匀速"啊哦啊哦"，而是成串说几句、停顿、再说。

## 动画参数（都在 meta.json 里）

| 动作 | 参数 | 做法 |
|---|---|---|
| 眨眼 | 3.2–6.8s 一次；快眨 140 / 普通 180 / 慢眨 420 / 连眨 150+170 | 换 `base-body-blink` |
| 抖耳 | 4.2–9.8s 一次；6 种序列按权重随机（见下） | 换形变帧，曲线按 Spine 实践 |
| 摆尾 | JS 逐帧驱动：双谐波（6.4–8.2s 慢摆 ±3° + 2.7–3.5s 次谐波 ±1.05°）+ 0.8s 微震颤 ±0.32°；每 3.5–12.5s 插一次阻尼快摆（±4.5–7.5°，弹簧过冲） | 只旋转 `part-tail`，pivot 81.02% 89.41% |
| 说话 | 三级开口 + 音节节奏（4–9 个音节一串，串间停顿 220–640ms） | 换 `base-mouth-1/2/3` |

**统一规格**：画布 864×1152 RGBA；bbox 高 1012、底边 1083、重心 x 486。
用 `object-fit: contain; object-position: center bottom` 摆放。

## 三个关键设计决定（改的时候别退回旧做法）

1. **耳朵绝不切层。** 耳朵和额头毛发连成一片，眉毛就在 y≈265，离耳根只有几十像素。
   切多边形出来静止时看不出来，一旋转切口就露成一条斜线（这条线我们踩过，就是上一版的问题）。
   现在的抖耳帧是**像素形变**生成：以耳根为轴旋转（耳根 35%、耳尖 115% 的距离增益，所以是甩不是平移），档位覆盖 -2° 到 +11°，影响区裁到眉毛以上，
   权重在 26px 内平滑衰减到 0 —— 没有接缝、不需要补色。

2. **说话不做音位口型。** 上一版的 `a`（竖椭圆大开口）和 `o`（收圆嘴唇）是人类的发音口型，
   放在猫脸上非常怪。现在改成猫的下颌开合：把开口围绕嘴线 y=465 竖向压缩成 3 级
   （0.30 / 0.56 / 0.82），形状从竖椭圆变成宽扁的缝，符合猫的开口形态。
   而且只合成回嘴部的羽化椭圆，**嘴部以外的像素与待机帧逐字节相同**，说话时身体绝不会抖。

3. **尾巴必须切层 + 加阴影。** 尾巴悬在身体外，切走后底座那里是透明的，摆动时交界处会裂出背景色。
   底座尾巴内侧填了深棕 (62,40,24) 并向外 34px 淡出，再叠 `tail-shadow`，看起来是自然的尾根暗部。

## 曲线参考（Spine 社区实践，这版按它重做）

抖耳的播放序列不是"0 → 满角度 → 0"，而是 Spine 里典型的生物曲线：

| 序列 | 权重 | 曲线 |
|---|---|---|
| 单边（左/右） | 6 + 6 | 预备 -2°(70ms) → 爆发 10°(55ms) → 回弹 4.5°(50ms) → 长回落(110ms) |
| 双耳同步 | 3 | 起势 6°(50ms) → 到位 11°(55ms) → 回落 6°(70ms) → 归零(120ms) |
| 单边连抽 | 2 + 2 | 10°(45ms) → 回(60ms) → 10°(45ms) → 长停(100ms) |
| 慢垂后抬起 | 1 | 4.5°(180ms) → 10°(240ms) → 4.5°(170ms) → 归零 |

要点：爆发段压短、回落段拉长（非对称节奏）；爆发前有反向小波谷（预备张力）；
冲过目标后过冲到中间位再归位（overshoot）。

尾巴同理：不再用固定周期正弦，而是两条不可通约周期的谐波叠加 + 0.8s 微震颤 +
偶发弹簧快摆 —— 人眼对"完美循环"天然排斥，参差才是"活"。

## 接到 IPTV 项目里要改三处

预览页只是页面级演示，正式引擎（`src/modules/avatar/SpriteAvatarEngine.js`）还没接：

1. `identity.js` / `packs.json` 把 packId 切到 `anan-cat-v3`；
2. `_resolveFile` 认 `blink` / `happy` / `mouth-1..3`；
3. `_init` 里挂：眨眼（四档随机）、抖耳（按 meta.json 里的 patterns 播放）、
   尾巴 rAF 驱动器（meta.json 里 tail.wave / tail.flick 的参数），
   说话时按音节节奏切嘴型而不是匀速 180ms。

## 已知限制

- 耳朵和尾巴都是"整帧 / 整层"级别的小动作，幅度刻意压得很小，为的是身体不晃。
  如果觉得还不够"活"，下一步值得加的是**瞳孔轻微偏移（看别处）**，
  但眼睛是高光绘制，需要单独做 2 帧再合成，属于另一轮工作量。
