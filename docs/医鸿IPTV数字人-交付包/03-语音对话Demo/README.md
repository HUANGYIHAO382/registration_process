# 医鸿 IPTV 数字人 · 语音对话 Demo

一句话概括：**对着麦克风说话 → 实时转成文字上屏 → 数字人听懂并回答 → 边说边动嘴、逐字高亮字幕。**

不装任何依赖，`node server.mjs` 就能跑。

---

## 一、怎么跑起来

```bash
cd demo-voice
node server.mjs
```

然后浏览器打开 **http://localhost:5173**

> 必须走 `http://localhost`，不能双击 HTML 打开。
> 浏览器只在 localhost 或 HTTPS 下才给麦克风权限，`file://` 一定拿不到。

---

## 二、三条语音通道（这是这个 Demo 最关键的设计）

| 按键 | 通道 | 说明 |
|---|---|---|
| `1` | 浏览器识别 | 零配置。Edge 通常可用；**Chrome 在国内大概率失败**，因为它走 Google 的语音服务 |
| `2` | 云端识别 | 录音上传后端转写。需要在 `config.json` 填 ASR key，最稳，也是上线该走的路 |
| `3` | 演示模式 | 不碰麦克风，按剧本逐字吐字。断网、没麦、现场翻车时的兜底 |

**为什么要三条？** 因为你没法保证现场那台电脑的麦克风和网络都是好的。
Demo 最怕的不是效果差，是**按下去没反应**。三条通道互为备份，哪条不通按一下就换。

`1` 报 `network` 错误时，页面会**自动降级**到 `2`（配了 key）或 `3`（没配），不会卡在那里。

## 三、配置真的语音识别 / 大模型

编辑 `demo-voice/config.json`，改完**刷新页面**即可，不用重启服务。

```jsonc
{
  "llm": {
    "enabled": true,
    "baseUrl": "https://api.deepseek.com/v1",
    "apiKey": "sk-xxxx",
    "model": "deepseek-chat"
  },
  "asr": {
    "enabled": true,
    "baseUrl": "https://api.siliconflow.cn/v1",
    "apiKey": "sk-xxxx",
    "model": "FunAudioLLM/SenseVoiceSmall"
  }
}
```

两处都只要求 **OpenAI 兼容协议**，所以换厂商只改 `baseUrl + model`：

| 用途 | 可用服务 |
|---|---|
| 对话 | DeepSeek、通义千问、Kimi、智谱、任意 OpenAI 兼容网关 |
| 语音识别 | SiliconFlow（SenseVoice）、阿里 DashScope、腾讯云、讯飞（需适配） |

**Key 不会下发到浏览器**，所有请求都经 `server.mjs` 代理转发。

不配也能完整演示——对话走内置的 6 组医疗剧本，语音识别走 `1` 或 `3`。

## 四、键位

| 键 | 作用 |
|---|---|
| `空格` | 开始说话；说话中再按 = 提前结束；数字人说话时按 = **打断** |
| `Esc` | 强制打断，回到待机 |
| `1` `2` `3` | 切换语音通道 |
| `H` | 播放一次危急兜底演示（胸痛/喘不上气 → 120） |
| 底部输入框 | 打字模拟说话，回车发送。麦克风调不通时用它，链路一样 |

## 五、对话是怎么处理的

```
用户说话
  ↓  ① 语音识别（三条通道任选）
  ↓  ② asr.partial 逐字上屏（让用户看见"它听懂了"）
  ↓  ③ 安全规则前置检查  ← 5ms，命中即短路，绝不交给大模型判断
  ↓  ④ 意图路由（挂号 / 血压 / 血糖 / 用药 / 报告 / 复诊 / 问候）
  ↓  ⑤ 回答（内置剧本 或 大模型流式）
  ↓  ⑥ 按句送 TTS（首句完整就开说，不等全文）
  ↓  ⑦ 播放 + 逐字高亮 + 口型跟着动
```

**第 ③ 步的顺序是硬要求。** 医疗场景里「胸痛、说不出话、呕血」这类词，不能让大模型自己决定怎么办。
命中关键词就直接播 120 指引，红屏大字，且不可被打断。按 `H` 可以看这段效果。

## 六、口型的现状与升级路径

现在是 **8 个 viseme 形状 + 约 9 帧/秒的节奏驱动**，不是真实音素驱动。

看起来像在说话，但不是严格对齐音节的。原因很实在：浏览器自带的 `speechSynthesis` 不返回音素时长，拿不到时间戳就没法精确对齐。

升级只需要改一处：换成语雀、火山、阿里这类**返回音素时间戳的 TTS**，然后把 `avatar.startSpeak()` 里的自动循环换成"按时间戳调 `setViseme()`"。
`avatar.js` 的对外接口不用动，界面代码一行都不用改。

## 七、文件结构

```
demo-voice/
├─ server.mjs        零依赖服务端：静态托管 + /api/chat + /api/asr 代理
├─ config.json       通道开关与 key（改完刷新即生效）
└─ web/
   ├─ index.html     1920×1080 舞台结构
   ├─ style.css      深墨绿医疗配色，正文 ≥32px
   ├─ app.js         状态机、TTS 队列、逐字高亮、键位
   ├─ voice.js       VoiceInput：三条通道，对外只发事件
   ├─ brain.js       安全规则 + 意图路由 + 剧本 + 大模型
   └─ avatar.js      数字人 SVG，两个角色，8 个口型
```

## 八、还没做、但上线前必须补的

1. **打断后的上下文衔接**：现在打断就是打断，用户问"刚才后面说什么"接不上。
2. **录音落盘与回放**：`JSONL` 事件录制，用于复盘和现场救场。
3. **真正的流式 ASR**：现在是整段上传，首字延迟比流式高约 0.5 秒。
4. **粤语/方言通道**：深圳场景刚需，`rec.lang` 改成 `zh-HK` 或换支持方言的 ASR 即可。
5. **数字人形象定稿**：现在这套 SVG 是工程占位，用来定尺寸和动效节奏，不是最终美术。
